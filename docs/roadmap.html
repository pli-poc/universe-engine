Roadmap & proof strategy

Each milestone validates an architectural risk before content complexity is added.

Phase 0 — design & site complete

  • Cinematic website and sticky navigation.
  • Technical design and subsystem contracts.
  • GitHub Pages CI/CD.
  • No engine runtime yet.

Phase 1 — coordinate proof in progress

  • WebGPU bootstrap.
  • Float64 universe + Float32 camera-relative renderer.
  • One star, one rotating planet, free-flight camera.
  • Precision tests across scales.

Phase 2 — planetary geometry

  • Cube-sphere quadtree, SSE LOD, deterministic heights and tile cache.

Phase 3 — atmosphere & seamless descent

  • Scattering LUTs, exposure and continuous orbit-to-ground traversal.

Phase 4 — local fidelity

  • Geological materials, procedural instances, local physics and temporal reconstruction.

Phase 5 — weather, ocean & stellar depth

  • Volumetric clouds, ocean waves, photosphere/corona and deterministic star field.
