Roadmap & proof strategy

Each milestone validates an architectural risk before adding another major subsystem. An implemented feature is not automatically a claim of production fidelity.

Phase 0 — design & site

Baseline complete Cinematic product pages, sticky navigation, explicit future-capture placeholders, engine design documents and GitHub Pages publishing.

Phase 1 — coordinate and rendering proof

Baseline complete WebGPU initialization, Float64 universe state, a rotating planet frame, camera-relative rendering, free flight, reverse-Z depth, first-frame validation and visible error reporting. Published runtime modules and shaders are isolated by commit ID.

Phase 2A — bounded planetary geometry

Baseline complete Cube-sphere addressing, shared procedural patches and complete parent-retaining tile-budget selection. The selector currently measures projected patch footprint; certified geometric-error bounds remain future work.

Phase 2B — seam-safe terrain

Implemented Cross-face neighbours, atomic 2:1 balancing, geometric edge stitching without skirts, coordinated source/target morphing and inspection controls. CPU invariant tests and browser coverage flights gate publication. See the full implementation specification for budgets, GPU contracts, transition behaviour, tests and limits.

Phase 2C — close-up precision and shading

Next Tile-local vertex origins to avoid planet-radius cancellation, terrain-derived lighting normals, richer geological material blending and a separate sea-level ocean surface. Ground inspection needs a clearance guard before any claim of walking or landing. These features are not part of 2B.

Phase 3 — physical atmosphere

Planned Replace the current terrain rim effect with atmospheric scattering, transmittance, aerial perspective and coherent stellar lighting/exposure. Validate continuous orbit-to-ground sky transitions before adding clouds.

Derived terrain residency

Planned Introduce generation queues, resource budgets, parent fallback and eviction when height, normal or material tile products are actually generated and retained. The current topology budget is not an asynchronous terrain-data cache. Profile before moving selection onto GPU compute.

Later systems

Volumetric weather, ocean waves, stellar photosphere/corona, local collision and landing dynamics, procedural instances, temporal reconstruction and additional celestial bodies remain subsequent milestones. Multiplayer and large-scale gameplay systems are outside the current technical proof.
