Planet virtualization & procedural terrain

A planet is stable mathematical identity; visible surface geometry is materialized on demand.

Cube-sphere quadtree implemented baseline

Each tile is addressed as {planetId, face, level, x, y}. One reusable grid topology renders all tiles.

cube face → tile UV → sphere direction → height displacement → camera-relative position

LOD CPU selector active

Projected geometric error controls subdivision. Hysteresis avoids thrashing. Skirts are implemented on mixed-LOD interior borders. The tile budget now stops refinement by retaining the parent tile, so reaching the budget cannot create holes. Neighbor balancing and geomorphing remain next.

screenErrorPx ≈ geometricError * projectionScale / distance
