Architecture baseline

Astrava universe engine

A WebGPU-native architecture for deterministic procedural star systems and seamless traversal from astronomical distances to local planetary gameplay.

Runtime status. Phase 1 is now implemented as a live WebGPU precision/rendering proof in demo.html. Quadtree LOD and physical atmosphere LUTs remain subsequent milestones.

Design goals

  • One world identity across solar, orbital, atmospheric and surface scales.
  • No dependence on one giant floating-point world space.
  • Deterministic, layered, cacheable procedural generation.
  • GPU-driven rendering where compute meaningfully reduces CPU orchestration.
  • Physical plausibility for light, atmosphere and orbital motion.

System decomposition

Astrava ├─ Universe Model Float64 authoritative state ├─ World Synthesis deterministic seeds + derived cache ├─ Rendering WebGPU / WGSL ├─ Simulation analytical far field + local physics └─ Persistence world version + sparse deltas

Non-goals for phase one

Multiplayer, economy, combat, AI populations and complex authoring tools wait until seamless scale is proven.
