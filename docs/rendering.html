WebGPU rendering architecture

GPU-driven where scale requires it, debuggable where the first milestone needs simplicity.

Render graph

Frame ├─ update reference frames ├─ camera-relative constants ├─ compute tile visibility / SSE ├─ compute instance/meshlet culling ├─ depth + opaque PBR ├─ atmosphere + aerial perspective ├─ clouds / volumetrics ├─ temporal resolve └─ tonemap + UI

GPU-driven evolution

Initial terrain selection may run on CPU. Once correct, selection and compaction move to compute and indirect draws.

Temporal stability

Motion vectors, stable jitter, temporal reconstruction and deterministic LOD transitions are requirements because procedural high-frequency detail otherwise shimmers badly.
